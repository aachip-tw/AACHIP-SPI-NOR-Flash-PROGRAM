# AACHIP-SPI-NOR-Flash-PROGRAM
AACHIP SPI NOR Flash PROGRAM，提供 SPI NOR Flash 的燒錄操作介面，供韌體備份、資料寫入、開發測試及設備維護使用。

實際支援的晶片、燒錄硬體、通訊模式、檔案格式，以及讀取、寫入、抹除與驗證功能，請參考各版本發布說明。

## 晶片與介面

SPI NOR Flash 常用於儲存開機程式、韌體、FPGA 組態及設備參數。

標準單線 SPI 常見訊號如下：

| 訊號 | 用途 |
| --- | --- |
| CS# | 晶片選擇，低電位有效 |
| CLK／SCLK | 通訊時脈 |
| DI／MOSI／IO0 | 傳入 Flash 的資料 |
| DO／MISO／IO1 | Flash 回傳的資料 |
| WP#／IO2 | 依模式作為寫入保護或資料訊號 |
| HOLD#／RESET#／IO3 | 依型號與模式具有不同功能 |
| VCC／GND | 電源與接地 |

各晶片的接腳、電壓及指令可能不同，請依完整料號與原廠資料手冊確認。Dual／Quad SPI 等模式是否支援，以軟體版本為準。

## 應用情境

- 備份與還原設備韌體。
- 寫入開機程式或 FPGA 組態資料。
- 更新產品參數及初始化內容。
- 協助 Flash 電路開發、測試與設備維修。

## 基本操作流程

1. 安裝軟體及燒錄硬體所需的驅動程式。
2. 確認 Flash 完整型號、容量與工作電壓。
3. 依硬體說明接線，確認供電、接地及控制腳位。
4. 啟動軟體，選擇對應裝置與晶片設定。
5. 若版本提供晶片識別功能，先確認識別結果。
6. 讀取並備份原始資料。
7. 載入資料檔案，確認容量、起始位址及操作範圍。
8. 依需要執行抹除與寫入，再進行資料驗證。

以上操作請依版本實際提供的功能執行。

## 使用注意事項

- 常見 SPI NOR Flash 有 1.8V、3.3V 等不同規格，禁止直接連接不相容的電源或訊號。
- NOR Flash 寫入通常只能將位元由 1 改為 0；需要由 0 改為 1 時，必須先抹除對應區域。
- 抹除會影響整個扇區、區塊或晶片，請先確認範圍並備份資料。
- 寫入需符合頁面邊界、忙碌狀態與寫入時間要求。
- 容量較大的晶片可能需要不同的定址模式，請使用符合型號的設定。
- 狀態暫存器、保護位元及 Quad Enable 等設定因型號而異，修改前請閱讀資料手冊。
- OTP、安全暫存器及永久鎖定區域可能無法還原，請勿當作一般資料區操作。
- 在板燒錄時，請避免原主控端同時驅動訊號，並防止反向供電。
- 操作期間保持供電穩定，不要拔除連線或中斷寫入。
